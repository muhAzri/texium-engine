# TeX engine files for Texium

Static files of the [BusyTeX](https://github.com/busytex/busytex) TeX engine (TeX Live 2023 compiled to
WebAssembly), published with GitHub Pages so Texium can compile LaTeX in the browser.
Generated by `npm run tex-engine:pack` (release `build_wasm_4499aa69fd3cf77ad86a47287d9a5193cf5ad993_7936974349_1`).

Set `NEXT_PUBLIC_TEX_ENGINE_URL` in Texium to this site's URL.

The files bundle TeX Live programs, each under its own free-software license (pdfTeX and LuaTeX: GPL).
Their source: https://github.com/busytex/busytex and https://tug.org/texlive/svn/.
